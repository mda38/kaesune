# フロントエンドのファイル移行表

Issue #175 着手時の `apps/web/src` 全 69 ファイルを対象とする。パスはすべて `apps/web/src/` からの相対パス。配置規則・所有権は [フロントエンド設計](frontend.md) を参照する。

元ファイルごとに配置先を固定する。複数の処理を含んでいた API / Mutation は export した処理単位で分割し、それぞれの定義先は一つとする。`queries.test.ts` は出金と請求の各所有 Feature へ分割する。型の API からの再 export は除き、定義先へ直接 import する。
